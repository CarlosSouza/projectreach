# Exports Halo reaches only through GetProcAddress (beyond its static and delay-load
# imports, which scripts/va-model.py adds automatically). One DLL!name per line. Each gets
# a guest address that dispatches to hpimp_<name>: HaloPad's service if one exists, else a
# stub that stops with the name. Names come from call sites (docs/EXECUTION-MODEL.md) and
# from traps seen while running the core.
kernel32.dll!InitializeCriticalSectionAndSpinCount
d3d9.dll!Direct3DCreate9
eula.dll!EBUEula
dsound.dll!DirectSoundCreate8
dinput8.dll!DirectInput8Create
shfolder.dll!SHGetFolderPathA
# ksimeui.dll (Keystone IME support) resolves these at run time
imm32.dll!ImmLockIMC
imm32.dll!ImmUnlockIMC
imm32.dll!ImmLockIMCC
imm32.dll!ImmUnlockIMCC
imm32.dll!ImmDisableTextFrameService
# msxml4.dll resolves these at run time (they are missing on Windows 95)
kernel32.dll!InterlockedCompareExchange
kernel32.dll!InterlockedExchangeAdd
# D3DX (statically linked in Keystone.dll) mutes the debug runtime
d3d9.dll!DebugSetMute
# USER32's dialog manager (halopad_user32.c, part 3): DefDlgProcA, and the built-in Button and
# Static classes' window procedures, which need guest addresses because applications subclass
# controls and call the previous procedure (GetProcAddress does not return the HaloPad* names)
user32.dll!DefDlgProcA
user32.dll!HaloPadButtonWndProc
user32.dll!HaloPadStaticWndProc
# the C runtime's message box (__crtMessageBoxA, 0x5dc1f0) resolves these at run time
user32.dll!MessageBoxA
user32.dll!GetActiveWindow
user32.dll!GetLastActivePopup
# DirectDraw: Halo's video memory query (0x580e70)
ddraw.dll!DirectDrawCreateEx
ddraw.dll!DirectDrawEnumerateExA
